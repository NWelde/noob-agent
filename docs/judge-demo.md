# Judge demo rehearsal

## Opening: 15 seconds

“Noob Agent is a bounded agent harness for constructing and testing a redstone
computer in Minecraft. The important property is that Minecraft performs the
computation. Our software observes actual blocks and signals and independently
checks the result.”

## Verified result: 40 seconds

Show the current readiness report. If the full-machine gate remains incomplete,
state that explicitly and show the accepted register's load, hold, and reset
evidence. Explain that arithmetic truth tables are diagnostics and the complete
machine still needs stored-program integration. Show the failed checks and real
repairs that led to acceptance; use genuine captured footage.

If the full-machine gate has passed, show both stored programs on the same
hardware, with outputs 3,8 and 14,3. Show the programming controls, STEP, latched
output, and HALT. Keep proof sequences at normal speed. Do not replace missing
machine evidence with computed overlays or a scripted output display.

## Production engineering: 30 seconds

“Every action has a declared bound and a durable record. A lost world response
stops execution instead of triggering a blind retry. Resuming checks the retained
world and preserves cumulative budgets. A module passes only when its independent
behavioral suite passes. We keep the failed attempts as well as the successes.”

Show one failure/recovery record and the reproducible software check command.
Distinguish software tests from live Minecraft checks. Describe the run as
assisted production, preserving the direct construction and design provenance.

## Close: 15 seconds

State the strongest result actually verified in the current trial. Identify the
remaining limitation if one exists. Have a tested local video ready if the live
demo fails. Use the checklist to confirm check-in by 4:15pm Pacific and remain
present through the award ceremony.
